# 🎓 Internship Tracker – MERN Stack

A full-stack Internship Management System built with the **MERN** stack (MongoDB, Express, React, Node.js).  
This system helps Admin, Faculty, and Students manage internship applications, approvals, tracking, and reports in a structured and user-friendly way.

## 🚀 Features
### 👨‍🎓 Student
- Submit internship details
- Upload required documents
- Track approval status
- View analytics of submissions
- Edit/update submitted internship info

### 👨‍🏫 Faculty
- Review student internship submissions
- Approve / Reject requests with comments
- Manage multiple student entries
- View reports and analytics

### 🛠 Admin
- Manage users (add/remove)
- Seed admin using scripts
- View complete analytics dashboard

## 🏗️ Tech Stack
### **Frontend**
- React JS  
- Tailwind CSS  
- React Router  
- Axios  
- CRACO (for config override)

### **Backend**
- Node.js  
- Express.js  
- MongoDB (Mongoose ORM)  
- JWT Authentication  
- Middleware-based access control
